This is a VS Code extension I created a while back. It's a color theme based on the old Trade Wars 2002 bulletin board game. Many might find the colors too garish, but I love it. 

The extension is available [on the Visual Studio marketplace](https://marketplace.visualstudio.com/items?itemName=paulabrams1.trade-wars-2002-color-theme), or you can install it from VS code by searching available extensions for keywords like "trade wars 2002".
